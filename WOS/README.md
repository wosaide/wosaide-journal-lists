# Web of Science journal lists

This directory stores Web of Science Core Collection journal-list snapshots
used by WOS Aide for journal matching and completion.

## Files

| File | Collection |
| --- | --- |
| `SCIE.csv` | Science Citation Index Expanded (SCIE) |
| `SSCI.csv` | Social Sciences Citation Index (SSCI) |
| `AHCI.csv` | Arts & Humanities Citation Index (AHCI) |
| `ESCI.csv` | Emerging Sources Citation Index (ESCI) |

## Official download source

Clarivate Master Journal List — Collection List Downloads:

https://mjl.clarivate.com/collection-list-downloads

Clarivate provides the individual Web of Science Core Collection lists from
this page. Access to the downloadable Core Collection files may require an
eligible Web of Science subscription/login, so this repository records the
official download page rather than an unstable authenticated file URL.

When refreshing these snapshots, download the corresponding collection lists
from the page above and keep the repository filenames unchanged.
