# CNKI journal source

This directory is reserved for CNKI journal-list snapshots that can be used by
WOS Aide as an optional matching source.

## Official source pages

- CNKI Journal Navigation:
  https://navi.cnki.net/knavi/journals/index
- CNKI / KNS8 Chinese Academic Journals search entry:
  https://kns.cnki.net/kns8?dbcode=CJFQ

CNKI does not currently expose a stable public direct-download URL for a
single complete all-journals XLSX/CSV file comparable to the Scopus or
ScienceDirect title-list downloads. For that reason, this README records the
official journal navigation/database entry points instead of inventing a file
URL.

If a CNKI list snapshot is added here later, record its exact export/source
page, acquisition date, and filename in this README so the data can be
reproduced and refreshed.
