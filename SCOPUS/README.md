# Scopus title lists

This directory stores official Scopus title-list snapshots used for journal
and source matching.

## Files and download addresses

### `ext_list_Jul_2026.xlsx`

Scopus Source title list, including discontinued sources.

- Official content/download page:
  https://www.elsevier.com/products/scopus/content
- Direct XLSX used for the current snapshot:
  https://downloads.ctfassets.net/o78em1y1w4i4/7xtaTxNiNcWRTeZkV86eNy/8df9934a6138c7e15817214c098deaf2/ext_list_Jul_2026.xlsx

### `Scopus_book_list_Q2.xlsx`

Scopus Book title list.

- Official content/download page:
  https://www.elsevier.com/products/scopus/content
- Direct XLSX used for the current snapshot:
  https://downloads.ctfassets.net/o78em1y1w4i4/2uPDv7HcQRnPoxj5xyGhBS/62cc5084eb5566e942271f09e37ccf80/Scopus_book_list_Q2.xlsx

Elsevier updates the Scopus source information regularly. Direct asset URLs
are versioned and may change; when refreshing, use the official content page
to obtain the newest files and update both the snapshot and this README.
